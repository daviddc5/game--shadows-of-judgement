# Audio

- `duel-theme.mp3`: "Briefcase And Bullet" (album "Midnight Dossier"), the
  owner's own theme for the battle screen. The source is a 3-minute track;
  this copy has the silent tail trimmed, a 1.2 s fade-out so it loops back
  into its quiet intro, and is normalised to about -17 LUFS (128 kbps MP3).
  It loops while a match is on (see `src/audio.js`); the ♪ button next to the
  help button mutes it, and the choice is saved on the device.
