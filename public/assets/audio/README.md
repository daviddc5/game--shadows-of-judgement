# Audio

- `duel-theme.mp3`: "The Winning Hand", the owner's theme for the battle
  screen. The source is a 2:51 track; this copy has the silent tail trimmed, a
  1.2 s fade-out so it loops back into its intro, and is normalised to about
  -17 LUFS (128 kbps MP3). It loops while a match is on (see `src/audio.js`);
  the ♪ button next to the help button mutes it, and the choice is saved on the
  device. It replaced an earlier theme, "Briefcase And Bullet".
